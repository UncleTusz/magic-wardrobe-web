# 魔法衣橱 · 静态页国内镜像（已退役）

> ⚠️ **本仓库已于 2026-09-25 清空退役，只保留这份说明。**

## 它曾经做什么

这是「国内访问 v1」方案的静态页镜像：把前端静态页、日报静态数据（`data/`）
与公开图片（`img/`）同步过来，由 GitHub Pages 托管，供国内访问。

## 为什么退役

该方案**已回退**，三个原因：

1. **门禁失效（主因）** —— 静态数据导出时所有条目都是 `locked: false`，
   含完整文字与全部图片，**任何人直接读 JSON 就能绕过口令**，
   让「前 2 篇免费、其余需口令」形同虚设
2. **两站版本不一致** —— 独立仓库无法随主仓库回退，排查时极易误判
3. **维护成本** —— 定时任务从 2 步变 5 步，每步都可能失败

## 现在用什么

**「国内访问 v2」：同一域名下的同源反代**，不需要静态镜像。

主站在 `*.pages.dev`（国内裸连实测可达，TTFB 0.54–0.81s），
`/api/*` 与 `/img/*` 由 `web/prototype/_worker.js`（Pages Advanced Mode）
反代到 Worker —— Function 在 Cloudflare 边缘执行，出口是 CF 内网，
不受国内 DNS 污染影响。**门禁完全在服务端，不需要把任何数据静态化。**

详见主仓库 `docs/09-国内访问方案v2-Pages同域反代.md`
（主仓库为 private）。
